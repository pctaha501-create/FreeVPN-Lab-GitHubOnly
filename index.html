1. Worker settings

2. Client profiles

The profile generator creates a VLESS-over-WebSocket URI and a basic Clash-compatible YAML profile. Test the generated profile on a device before sharing it.

3. Check your current public IP

This checks the public IP visible to this browser only. It does not rate an IP as “clean” and does not test a VPN connection. To test the tunnel, connect a client and check the IP again from that client/device.

No IP check run.

Deployment checklist

  • Deploy the Worker from GitHub Actions after adding the repository secret CLOUDFLARE_API_TOKEN and repository variable CLOUDFLARE_ACCOUNT_ID.
  • Set the Worker secret named UUID to the same UUID entered above. Use a strong random UUID and keep it private.
  • Test /health before importing profiles.
  • Workers have quotas and outbound socket restrictions. This is a prototype, not an unlimited VPN service.
