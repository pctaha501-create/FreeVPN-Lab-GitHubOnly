FreeVPN Lab

Exploring VPN tooling with GitHub — honestly, safely, and without pretending CI runners are permanent servers.

GitHub only · No Cloudflare

Important limitation

This page is not a VPN. GitHub Pages serves static websites, while GitHub Actions runs temporary automation jobs. Neither provides a persistent VPN endpoint or routes your device's internet traffic.

What we can build here

  • A public project website and step-by-step documentation.
  • Automated checks and builds with GitHub Actions.
  • Later, a local configuration guide or client-side validator that never uploads private keys.

What a real VPN needs

A real VPN needs a device or hosting service that accepts a tunnel and forwards traffic. If you have no VPS or other always-on host, GitHub alone cannot provide that endpoint. We will not use temporary Actions runners as a persistent tunnel or proxy.
